# План подготовки европейской выборки для production

## Цель и зафиксированные критерии

Подготовить новые объявления из `Cars.db`, нормализовать их через Master DB и опубликовать в европейском каталоге Chestny Prigon.

- Легковые: Renault Megane, Peugeot 308, Peugeot 3008, Citroen Grand C4 Spacetourer / C4 Spacetourer, SEAT Ateca, Opel Insignia; первая регистрация 2022–2023; пробег до 100 000 км.
- Микроавтобусы: Mercedes-Benz Sprinter, Volkswagen Crafter, MAN TGE, Fiat Ducato; первая регистрация 2022–2023; дизель; пробег до 150 000 км.
- Учитывать только новые объявления, которых ещё нет в каталоге Chestny Prigon; нужны исходная цена и фото.
- Использовать доступную исходную цену Brutto и отдельно подтверждённое Netto, если оно есть. Не вычислять Netto из Brutto.
- Для легковых показывать предварительный расчёт под ключ. Для микроавтобусов показывать цену в ЕС и пометку: «Итоговый расчёт в ходе консультации с менеджером».
- Рабочая ветка сайта: `main`. Не затрагивать посторонние незакоммиченные изменения Master checkout.

Сохранить воспроизводимый allowlist и отчёт по моделям и классам. Не подгонять список под прежнюю оценку 3 852: при расхождении сохранить фактический результат и объяснить разницу.

**Статус:** выполнен, чекпоинт 1.

- Сводка по критериям и строкам `Cars.db`: `output/europe-customer-cohort/candidates.json`.
- На момент чекпоинта 1 в Master DB было 2 совпадения; после завершения этапа 2 весь allowlist сопоставлен с Master UUID.
- Фактический состав по актуальным данным: 2 997 легковых и 863 микроавтобуса. Прежнее число 3 852 и разбиение 2 977/875 не подтверждаются текущей базой.

**Итог этапа:** allowlist передан в Master DB, целевые классы назначены и сверены в чекпоинте 2.

### 2. Подготовить данные в Master DB

По зафиксированному allowlist передать только выбранные записи из `Cars.db` штатным Mobile.de импортёром. Нормализовать поля, цену и фото. Пометить выбранные микроавтобусы классом VAN в Master DB. Сверить количество, классы, цену и изображения; сохранить отчёт.

**Статус:** выполнен, чекпоинт 2.

- Штатным batch-importer в production Master DB загружены все 3 860 строк из ограниченного SQLite-среза `selected-cars.db`; 39 пакетов, 3 860 imported, 0 updated, 0 skipped, 0 rejected, 0 errors.
- Master DB сопоставляет все 3 860 Source ID с уникальными Master UUID. Создан локальный `output/europe-customer-cohort/master-allowlist.json` с точными соответствиями ID, модельной группой, классом, ценой и числом текущих изображений.
- Проверено: у всех 3 860 есть положительная цена в EUR и хотя бы одно текущее изображение; всего 6 076 текущих изображений. Подтверждённое Netto присутствует у 169 объявлений. У остальных 3 691 доступна исходная цена без отдельного подтверждённого Netto; это не исключает их из согласованной выборки.
- В Master DB по явному allowlist исправлена классификация только целевых строк: 2 997 CAR, 863 VAN. Изменено 584 строки, которые общий классификатор отнёс не к заданному заказчиком классу.
- Все 3 860 строк сейчас имеют `availability_state = unknown`; загрузка данных в Master не делает их автоматически публичными.
- Манифест importer выдал 21 eligible / 37 review / 3 802 not_publishable по общим правилам Master (включая общие ограничения возраста/мощности и неполное распознавание марок). Эти общие оценки не являются решением по целевой выборке заказчика и не должны сужать allowlist. На этапе 3 сайт/API должны принимать именно сохранённую целевую выборку и согласованные критерии.
- Импорт не публиковал объявления в Chestny/Supabase и не менял видимость существующих записей.

**Следующий этап:** этап 3 — подготовить код Chestny `main` и контракт Master API для точного allowlist из 3 860 строк, поддержки исходных Brutto/Netto, расчёта легковых и карточек VAN без расчёта под ключ.
