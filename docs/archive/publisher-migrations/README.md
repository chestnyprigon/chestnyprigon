# Архив миграций Telegram-публикатора

SQL-файлы в этой папке сохранены для проекта публикатора и не являются миграциями базы `chestny-prigon`.

Они не должны находиться в `supabase/migrations`: используют таблицы `telegram_publish_sessions` и `telegram_posts`, которых нет в миграциях этого проекта, а планировщик вызывает отдельный deployment `chestny-prigon-publisher.vercel.app`.

Для применения этих изменений восстановите их в репозитории и проекте Supabase публикатора после проверки его схемы и секретов Vault.
