# Предварительный расчёт автомобиля из Европы до Минска

Расчёт предназначен для физического лица и использует цену Netto из объявления Mobile.de. Если источник не даёт Netto, объявление не включается в европейский каталог с расчётом. Брутто-цена не пересчитывается в Netto.

Возрастную категорию для предварительного расчёта определяем по первой регистрации из объявления. Нормативные тарифы привязаны к дате выпуска автомобиля; дата первой регистрации используется как доступный прокси-показатель, а не как дата выпуска. Итоговую категорию необходимо сверить с документами автомобиля при оформлении. Это расчётная оценка, а не таможенное заключение.

## Состав расчёта

1. Цена Netto продавца в евро.
2. Услуги компании в ЕС: 2,5% от Netto.
3. Перевод: 1,5% от Netto и услуги компании в ЕС.
4. Доставка до Минска: 2 200 евро.
5. Услуга компании: 1 000 евро.
6. Таможенный платёж физического лица по объёму двигателя и возрастной категории, определённой по первой регистрации.
7. Утилизационный сбор физического лица по возрастной категории, определённой по первой регистрации.
8. Пересчёт евро в белорусские рубли по официальному курсу НБРБ.

Льготный режим включён по умолчанию и доступен переключателем. Он уменьшает только таможенный платёж. Применимость льготы зависит от права конкретного человека и проверяется отдельно.

Все суммы обозначаются как предварительные. Итоговые платежи определяются при оформлении.

## Данные каталога

- Первая регистрация используется для фильтра каталога и возрастной категории расчёта.
- Для цены берётся Netto из структурированных данных объявления Mobile.de (`price.nt.amount`). Brutto не пересчитывается в Netto.
- Значение брутто и вычисления из брутто не подменяют Netto.
- Объём двигателя нужен для таможенного расчёта.

## Источники ставок

- Таможенные тарифы: [Решение Совета ЕЭК № 107, приложение 2](https://eec.eaeunion.org/upload/medialibrary/c30/8uxy42l5mogucd8lnp9q3wtc4igi2vki/Prilozhenie-2_107.pdf), таблица 2.
- Ставки утилизационного сбора физического лица при ввозе легкового автомобиля для личного пользования: постановление Совета Министров № 195, приложение 2, подпункт 1.3. В действующей редакции ставки составляют 624,92 BYN до трёх лет включительно и 1 282,02 BYN старше трёх лет. МНС подтверждает, что с 29.04.2026 ставки определяются постановлением № 195: [разъяснение МНС](https://nalog.gov.by/news/35105/) и [текст постановления](https://pravo.by/document/?guid=12551&p0=C22600195).
- Льготный режим: Указ Президента № 140 предусматривает возмещение 50% таможенных пошлин и налогов только отдельным категориям физических лиц и для личного пользования; это не общая скидка на любой импорт. [текст Указа № 140](https://www.alta.ru/tamdoc/19bl0140/), [разъяснение МНС о личном пользовании и злоупотреблениях льготой](https://nalog.gov.by/news/31915/).
- Официальный курс: [API НБРБ](https://api.nbrb.by/exrates/rates?periodicity=0).

## Текущий статус подключения

Проверенный detail-ответ Master API содержит `price.amount` типа `original_asking`; существующее `reported_net_amount` пока не выведено в API. Локальный патч добавляет проекцию этого уже сохранённого Netto в ответ API; он не применён и не развёрнут. Для локальной проверки калькулятора есть демонстрационная карточка.
