# Честный пригон

Отдельный сайт для подбора, проверки, доставки и растаможки автомобилей из Кореи в Беларусь.

Проект не изменяет Autoexport 2.0 и не использует его production-ключи. Autoexport является источником наработок и данных для независимого импорта.

Согласованный порядок разработки и статусы: [`docs/roadmap.md`](docs/roadmap.md).

## Статус

- Этап 1: отдельный Next.js-проект создан.
- Этап 2: визуальный каркас в стиле честныйпригон.бел согласован.
- Этап 3: реализован интерфейс каталога с фильтрами, сортировкой и подробной карточкой автомобиля на реальных данных.
- Supabase: отдельный remote-проект `chestny_prigon` привязан, миграция, RLS и доступы проверены. Контролируемый пилот Encar загрузил 40 сырых записей, 34 нормализованных автомобиля и решения фильтрации.
- Каталог: после углублённой проверки отчётами Encar публично оставлены 9 автомобилей. Для них доступны фото, безопасные характеристики, комплектация, результаты осмотра и расчёт. Объявления с признаками проката, такси, коммерческого использования или ДТП не публикуются автоматически.
- Калькулятор: подключён предварительный USD-профиль по структуре Emavto из HAR от 07.08.2026. Ставки изолированы и будут заменены после подтверждения заказчиком.
- Админ-панель в MVP не планируется; каталог и поддержка обслуживаются разработчиком.
- На первом релизе используется только Корея.

## Запуск

Скопируйте `.env.example` в `.env.local`, заполните ключи отдельного Supabase и запустите:

```bash
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```

Проверка правил и безопасный dry-run Encar:

```bash
npm run test:encar
npm run encar:pilot -- --limit=20
npm run encar:enrich -- --apply-screening
```
