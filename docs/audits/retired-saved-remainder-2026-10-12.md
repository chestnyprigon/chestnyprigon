## Как освобождены ID

Записи run и очереди не удалялись. У выбранных отменённых/неуспешных записей
сохранена метка `discovery_release` с причиной, временем, ID отменяемого run
и предыдущим статусом очереди. Всего помечена 2 381 историческая запись
для 1 190 уникальных ID: текущая очередь, её исходные копии и одна старая
ошибка пустого detail для того же ID.

Новая view `chestny_discovery_reserved_queue` исключает только явно освобождённые
резервы. Остальные исторические записи продолжают защищать от дублей.
На неё переведены локальный discovery, подготовка VPS-очереди и серверная
функция регистрации страницы поиска. Все проверки каталога, staging,
связей ID, квот и offset сохранены.

Миграция `20261012140000_release_retired_queue_discovery_reservations.sql`
применена к проекту ЧП и зарегистрирована в истории миграций.
Обе правки поиска установлены на Mac mini. Старый файл `active-run` вместе
с параметрами запуска перемещён в закрытый архив состояния Mac mini.
